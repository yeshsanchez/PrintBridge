WHAT IT IS
------------------------------------------------------------------------
Your Canon PIXMA G1010 is USB-only — no wi-fi. PrintBridge turns this
MacBook (the one plugged into the printer) into a little print server so
ANY device on your wi-fi (phone, another laptop) can print by opening a
web page. It looks and feels like a real app — but there's nothing to
install on the other devices; they just open a link.

What the app can do now:
  * Pick ONE or MANY files at once and print them in a batch
  * Set print options: Paper size, Layout, Color/B&W, Copies
  * See a LIVE queue (updates on its own) with each job's status
  * On an iPhone: open the link -> Share -> "Add to Home Screen" to get
    a real app icon that opens full-screen


HOW IT WORKS (the whole trick)
------------------------------------------------------------------------
We did NOT write a printer driver. macOS already knows how to talk to the
G1010 through its built-in printing system called CUPS (the command-line
tools `lp` and `lpstat`). PrintBridge is just a small middleman:

   [phone / laptop]                     <- any device on your wi-fi
        |
        |  1. uploads a file over HTTP (via the web app)
        v
   [this MacBook: PrintBridge server]   <- a small Node.js program
        |
        |  2. hands the file to CUPS with:  lp -d <queue> [options] <file>
        v
   [macOS CUPS print queue]             <- Canon's driver lives here
        |
        |  3. USB
        v
   [Canon PIXMA G1010]                  <- prints!

So all PrintBridge does is: receive a file -> run `lp` -> done.
It also has a password (an "API key") so random people on the wi-fi
can't spam your printer.

Your link (works from any device on either ZTE wi-fi band):
   http://192.168.1.7:3000
Use the IP — it works across BOTH wi-fi bands. (The friendly name
"printbridge.local" also works, but only when the device is on the SAME
band as the Mac; this router doesn't pass the name between the 2.4G and
5G bands. The IP has no such issue, so it's the one to bookmark.)

========================================================================
 WHAT YOU NEED TO DO
========================================================================

STEP 1 — Install Canon's driver & plug in the printer
------------------------------------------------------------------------
  * Download the official "Canon PIXMA G1010" macOS driver from Canon's
    support site and install it.
  * Plug the printer into this Mac by USB, turn it on.
  * Add it in: System Settings -> Printers & Scanners.
  * Print a test page from Preview to confirm macOS can print at all.
    (If macOS can't print, PrintBridge can't either — fix this first.)


STEP 2 — Find your printer's "queue name"
------------------------------------------------------------------------
  Open Terminal and run:

      lpstat -p

  You'll see something like:
      printer Canon_G1010_series is idle.

  The word after "printer" (e.g. Canon_G1010_series) is your QUEUE NAME.
  Copy it — you need it in the next step.

  >>> REMINDER (do this once the printer is installed): <<<
  Get the G1010's REAL list of supported paper sizes + options with:

      lpoptions -p <your-queue-name> -l

  The app's Paper choices right now are just common presets
  (A4 / Letter / Legal / 4x6). Once you have the real list from the
  driver, tell Claude and we'll update the app's Paper/size options to
  match exactly what the G1010 actually supports.


STEP 3 — Fill in the config file (.env)
------------------------------------------------------------------------
  There's already a .env file in this folder with dummy test values.
  Open it and set the real values:

      PORT=3000
      CUPS_QUEUE_NAME=Canon_G1010_series     <- paste YOUR queue name here
      API_KEY=some-long-random-password       <- see below
      NODE_ENV=production

  To make a good random API key, run this in Terminal and paste the result:

      openssl rand -hex 24

  (The API key is the password other devices type once in the app's
   Settings — the gear icon, top-right.)


STEP 4 — Start it and test on THIS Mac
------------------------------------------------------------------------
  In Terminal, from this folder:

      npm start

  Then open http://localhost:3000 , tap the gear (settings) and paste the
  API key, pick one or more PDF/JPG/PNG files, choose your options
  (paper, layout, color, copies), and hit Print. It should come out of
  the G1010.

  (Press Ctrl+C in Terminal to stop it.)


STEP 5 — Test from your PHONE (the whole point)
------------------------------------------------------------------------
  * Make sure your phone is on the wi-fi (either ZTE band is fine).
  * On your phone's browser, go to:

        http://192.168.1.7:3000

    Type it exactly — with http:// and :3000 . This IP works across BOTH
    bands. (The name http://printbridge.local:3000 also works, but only
    when the phone is on the SAME band as the Mac, so prefer the IP.)

    If the IP ever changes, find the new one on the Mac with:
        ipconfig getifaddr en0
  * Tap the gear, enter the API key, pick a file, Print. Watch it print!
  * Optional: Share -> "Add to Home Screen" for an app icon.


STEP 6 — Make it run by itself (auto-start on login)
------------------------------------------------------------------------
  So you don't have to run `npm start` every time, install the
  "LaunchAgent" (it starts PrintBridge automatically at login and
  restarts it if it crashes):

      cp "launchd/com.yeshua.printbridge.plist" ~/Library/LaunchAgents/
      launchctl load ~/Library/LaunchAgents/com.yeshua.printbridge.plist

  Logs (if something breaks) go to:
      ~/Library/Logs/printbridge.out.log
      ~/Library/Logs/printbridge.err.log

  To stop/restart it after changing settings:
      launchctl unload ~/Library/LaunchAgents/com.yeshua.printbridge.plist
      launchctl load   ~/Library/LaunchAgents/com.yeshua.printbridge.plist


STEP 7 — Stop the Mac from sleeping (or it can't receive jobs)
------------------------------------------------------------------------
  A sleeping Mac can't accept print jobs. Turn on:
      System Settings -> Displays -> Advanced ->
      "Prevent automatic sleeping on power adapter when display is off"
  Keep it plugged in and the lid open (or clamshell on external power).

========================================================================
 QUICK TROUBLESHOOTING
========================================================================
  "Missing required env var" on start .. fill in CUPS_QUEUE_NAME + API_KEY in .env
  "500 Failed to submit print job" ..... wrong queue name, or printer off/offline.
                                         Re-run `lpstat -p`, check macOS can print.
  "401 Invalid or missing API key" ..... the key typed doesn't match API_KEY in .env
  Phone can't load the page ............ Use the IP (http://192.168.1.7:3000), NOT
                                         printbridge.local — the name doesn't cross
                                         wi-fi bands on this router. Also check: on
                                         the wi-fi? Mac awake? http:// and :3000 typed?
  A paper size won't print right ....... the app's presets may not all match your
                                         G1010. Get the real list with:
                                         lpoptions -p <queue> -l  (see Step 2 reminder)
  Prints garbage ....................... only send PDF/JPG/PNG. Convert weird files
                                         to PDF first.

Full details are in README.md. The original spec is in PrintBridge_PROJECT.md.
